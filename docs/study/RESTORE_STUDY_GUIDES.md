# Restoring the 7-day study guides

**If the following files are all present in `docs/study/`, you are done.** They were regenerated from `.cursor/plans/7-day_study_&_execution_guide_ea9ef265.plan.md`; compare with Local History if you had customized copies.

During a folder restructure, the files that used to live in `guides/` may be missing from `docs/study/`. Expected names:

- `00_Master_Plan.md`
- `01_Day1_Guide.md` … `07_Day7_Guide.md`
- `Concepts_Reference.md`

## How to get them back

1. **Cursor / VS Code Local History** — Right-click `docs/study` (or the workspace) → **Timeline** / **Local History** and restore the deleted `.md` files.
2. **OneDrive or cloud backup** — Use version history if the project folder is synced.
3. **Another machine or clone** — Copy the `guides/` or `docs/study/` tree from a backup.
4. **Regenerate** — Ask your AI assistant to recreate guides using the outline in `.cursor/plans/7-day_study_&_execution_guide_ea9ef265.plan.md` (content will need your review).

After recovery, keep everything under **`docs/study/`** so paths stay consistent with the root [`README.md`](../README.md).
